This SoK paper provides an overview of prompt injection attacks on large language models (LLMs). It covers the basic LLM prompt pipeline and explains how (indirect) prompt injection attacks are able to leverage this pipeline to achieve high success rate especially in large and powerfull LLMs. How prompt injection success is influenced by reinforcement learning from human feedback (RLHF) and other fine-tuning methods that aim at increasing instruction following capabilities of LLMs is discussed in detail. Furthermore, the paper describes the most used manual and automated techniques for injection prompt construction and optimization. This includes manual prompt writing, semi-automated and LLM-assisted prompt rephrasing, as well as gradient based optimizations using loss minimization and shadow models. Besides being formally introduced and explained, the approaches are also compared in aspects of their advantages, disadvantages, and aaplicability. Last but not least, the paper outlines basic defense approaches by mainly focusing on instruction-data separation and potential applications of interpretability as a basis for prompt injection defense. The full PDF version is available [here](https://github.com/LunaNordin/Prompt-Injection-Attacks/blob/main/Prompt%20Injection%20Attacks.pdf).

The paper was written as a submission to the "HoT-X Conference 2026", a seminar on XAI and security of machine learning held by the [IntelliSEC research group](https://intellisec.de/) at KIT. This repository contains the paper's LaTeX resources as well as a between the original submission and the camera ready paper (for paper versions see commit tags).
